## Notes

The motion occupies roughly 384&ndash;2150ms of the 3200ms cycle; the last second is deliberate stillness before it rings again. That pause is part of the loop — trimming it turns a periodic attention cue into a continuous jitter. The scene also appears at two sizes: 260px standalone and 135px as the icon inside the permission sheet.
